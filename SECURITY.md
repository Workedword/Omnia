# Security reports

Please report suspected vulnerabilities privately to **omniastreams@gmail.com**. Include the affected version, reproduction steps and likely impact. Use a synthetic account or redacted example; never send a real user's password, session token or configured provider URL.

Keep working exploits and sensitive data out of public issues while the report is reviewed. We will review the report and coordinate a fix where needed. There is currently no paid bug bounty or guaranteed response deadline.

The latest published platform releases are the starting point for security maintenance. Older versions may need updating before a fix can be validated. Production credentials and account data are stored outside this repository.
