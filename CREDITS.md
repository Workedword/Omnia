## Interface and feature research

These projects informed our research and design discussions. They are credited as references, rather than as a claim that every feature or interface is included in Omnia.

| Project | Research area |
| --- | --- |
| [Ultra TV](https://github.com/vantaflow/ultra-tv) | IPTV navigation, layouts and provider workflows. |
| [APL-TV](https://github.com/Knikt/APL-TV) | Living-room browsing and remote-friendly presentation. |
| [VodMax](https://github.com/silirim/VodMax) | IPTV libraries and provider capabilities. |
| [NuvioPlusIPTV](https://github.com/homelessbrian/NuvioPlusIPTV) | Live-TV and IPTV feature research. |
| [TizenTube](https://github.com/reisxd/TizenTube) and [TizenTubeCobalt](https://github.com/reisxd/TizenTubeCobalt) | YouTube TV interface and runtime research. |
| [NuvioHub](https://github.com/jollran2005/NuvioHub) | Setup and community workflow ideas. |
| [Nuvio-Echo](https://github.com/Laking22/Nuvio-Echo) | Community feature and presentation research. |

| [Nuvio-ReSeq](https://github.com/abbaskip/Nuvio-ReSeq) | Interface and feature research. |
| [IPTV Deck](https://iptv-deck.com/) and [Trinity TV Player](https://trinitytvplayer.com/) | IPTV presentation and feature references. |

We also thank the maintainers of the libraries, metadata services and community add-ons that make this ecosystem possible, and everyone who reports bugs, tests releases or contributes improvements.
